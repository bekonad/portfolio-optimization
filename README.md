# Portfolio Optimization with Time Series Forecasting

This project applies time series forecasting and modern portfolio theory (MPT)
to optimize a portfolio consisting of TSLA, BND, and SPY.

## Structure
- notebooks/: EDA, modeling, forecasting
- src/: reusable code
- data/: processed datasets
- tests/: unit tests
- scripts/: execution scripts

## Data Source
Historical market data fetched using YFinance.
